# Midnight Slots

Учебный проект игрового автомата с виртуальными монетами и физической кнопкой на ESP32. Сайт показывает барабаны, профиль и рейтинг, а сервер определяет результат игры и хранит балансы. ESP32 отправляет нажатие кнопки в браузер и получает результат для световой и звуковой индикации. Реальные деньги не используются.

## Запуск сайта

Нужен Node.js версии 18 или новее. Сервер использует встроенные модули Node.js, устанавливать сторонние зависимости не требуется.

```bash
node server.js
```

Откройте в браузере **http://localhost:3000**. По умолчанию сервер слушает только локальный адрес `127.0.0.1` на порту `3000`. Для остановки нажмите Ctrl+C в терминале.

При каждом запуске сервер создаёт или обновляет администратора и выводит в терминал его новый случайный пароль. Имя по умолчанию — `admin`; его можно изменить через `ADMIN_USER`. Сохраните пароль из вывода текущего запуска: после перезапуска он меняется. Обычный пользователь не может получить роль администратора при регистрации.

```bash
ADMIN_USER=admin PORT=3000 node server.js
```

После изменения файлов в `public/` перезапустите сервер: статические файлы загружаются в память при старте.

## Игра и страницы

Зарегистрируйтесь или войдите в профиль. Имя должно содержать от 3 до 20 латинских букв, цифр или символов подчёркивания. Пароль — от 10 до 128 символов; слишком распространённые пароли и пароли с именем пользователя отклоняются.

Новый игрок получает 1000 монет. Спин стоит 10 монет; если все три цифры совпали, сервер начисляет 500 монет. Цифры от 1 до 7 выбираются сервером с помощью `crypto.randomInt`. Пауза между спинами по умолчанию — 1,5 секунды. При недостаточном балансе спин не запускается. Шанс трёх одинаковых цифр при обычном спине — 1/49.

Страницы используют общий интерфейс: `/machine` — автомат, `/profile` — вход и баланс, `/leaderboard` — десять лучших игроков по балансу без администратора, `/controller` — подключение ESP32. Неавторизованный посетитель перенаправляется в профиль. Админ-панель видна администратору на странице автомата: она позволяет менять баланс, сразу начислить джекпот или сделать следующий спин выигрышным. Последний режим действует на следующий спин любого игрока.

На фоне падают и вращаются вишни; при выигрышном спине вишни устремляются вверх, появляются пиксельные искры и страница кратко трясётся. Настройка системы `prefers-reduced-motion` отключает движение и эффект выигрыша.

## ESP32: подключение

Нужны ESP32 DevKit, кнопка, красный и зелёный светодиоды с подходящими токоограничивающими резисторами, пассивный буззер и USB-кабель для передачи данных.

| Компонент | Подключение |
| --- | --- |
| Кнопка | GPIO 19 → кнопка → GND |
| Красный LED | GPIO 21 → LED и резистор → GND |
| Зелёный LED | GPIO 22 → LED и резистор → GND |
| Пассивный буззер | GPIO 18 → буззер → GND |

Учитывайте полярность светодиодов. Кнопка использует внутреннюю подтяжку `INPUT_PULLUP`: при нажатии вход становится LOW. Загрузите `esp32_slots_button.ino` через Arduino IDE, выбрав вашу плату и порт. После загрузки закройте Serial Monitor, чтобы освободить порт.

Откройте сайт на `localhost` в Chrome или Edge, войдите, перейдите на страницу автомата и нажмите «Подключить ESP32». Выберите порт платы. Web Serial работает в поддерживаемом браузере и безопасном контексте; `localhost` подходит для локальной работы. Скорость соединения — **115200 бод**. После перезагрузки или закрытия страницы порт нужно подключить снова.

Цепочка работы: кнопка отправляет строку `SPIN\n` → браузер запрашивает `POST /api/spin` → сервер возвращает результат → браузер показывает его и отправляет плате `WIN\n` или `LOSE\n`. При выигрыше работает зелёный LED и мелодия, при проигрыше — красный LED и мелодия. Кнопка и индикация обрабатываются в основном цикле без длительных задержек; при запуске скетч отдельно проверяет оба LED с задержками по 300 мс.

Если плата не реагирует, проверьте USB-кабель и выбранный порт, закройте Serial Monitor, подключите плату именно на странице автомата и убедитесь, что выполнен вход. Затем отдельно проверьте, приходит ли `SPIN`, запускается ли спин и приходят ли на плату `WIN`/`LOSE`; проверьте проводку, полярность и резисторы. Работа конкретной платы должна проверяться на оборудовании.

## Настройки сервера

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Адрес прослушивания |
| `PORT` | `3000` | HTTP-порт |
| `ADMIN_USER` | `admin` | Имя администратора |
| `DATA_DIR` | `data` в папке проекта | Каталог данных |
| `SPIN_COOLDOWN_MS` | `1500` | Интервал между спинами в миллисекундах |
| `MAX_USERS` | `10000` | Максимальное число пользователей |
| `API_RATE_PER_MIN` | `120` | Общий лимит запросов к API на IP за минуту |
| `ALLOWED_HOSTS` | пусто | Разрешённые значения заголовка Host через запятую |
| `TRUST_PROXY_HOPS` | `0` | Число доверенных прокси для определения IP |
| `NODE_ENV` | режим разработки | Значение `production` включает Secure-cookie и дополнительные HTTPS-заголовки |

В текущем коде `ADMIN_PASSWORD` не используется: пароль администратора генерируется при каждом запуске. Для размещения в сети необходимы корректно настроенный HTTPS и обратный прокси; production-cookie требует HTTPS. Проект предназначен для обучения, а не для игры на реальные деньги.

## Данные и безопасность

`data/users.json` хранит пользователей, хэши паролей и балансы; `data/audit.log` — события аудита. Пароли хэшируются с солью через scrypt. Данные пользователей сохраняются в файл, а сессии хранятся в памяти и теряются при перезапуске сервера. Время бездействия сессии — 30 минут, максимальная длительность — 8 часов.

Баланс, роль и результат спина проверяются сервером. Для изменяющих запросов используются проверка источника и CSRF-токен; сессионная cookie имеет флаги HttpOnly и SameSite. Для API действует общий лимит запросов. В текущем сервере отдельная блокировка аккаунта после неудачных попыток входа не реализована.

## Файлы проекта

`server.js` — HTTP-сервер, API, авторизация и игровая логика; `public/index.html`, `public/style.css`, `public/app.js` — интерфейс и Web Serial; `public/logo.png` и `public/favicon.png` — изображения; `esp32_slots_button.ino` — прошивка контроллера; `test/security.test.js` — тесты сервера.

Запуск тестов:

```bash
npm test
```

При последнем запуске часть тестов безопасности завершилась ошибкой: некоторые ожидания тестов не совпадают с текущим поведением сервера, в частности для администратора и ограничения попыток входа.
